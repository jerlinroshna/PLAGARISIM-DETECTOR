AST Structural Matching

Code is parsed into Abstract Syntax Trees. Renaming variables, modifying indentation, or reordering commutative statements preserves the syntactic structure and is screened accurately.

Calibrated Scoring

Composite scores use 40% Token Similarity and 60% AST Structural Alignment. Boilerplate template code and standard libraries are normalized to prevent false positives.

Zero-Execution Safety

Uploaded code is strictly analyzed as static text and AST trees. Your code is never executed, and student submissions are never accessible to other students.

Permitted vs. Prohibited Practices

Permitted (Good Academic Practice) Prohibited (Academic Integrity Violation)
✓ Permitted

Discussing algorithmic concepts, whiteboard pseudocode, or high-level problem-solving approaches with classmates.

 ✗ Prohibited

Sharing, copying, or sending raw source code, repository files, or screen captures of assignment solutions.
✓ Permitted

Consulting official documentation, textbooks, or standard library APIs with proper citation in source comments.

 ✗ Prohibited

Taking solutions from previous years' student archives, online repositories, or public repositories without faculty authorization.
✓ Permitted

Independently implementing and testing algorithms from scratch in allowed languages.

 ✗ Prohibited

Automated or manual variable renaming ("cosmetic obfuscation") designed to disguise copied code structure.
